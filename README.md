# ScoutBolt 🔩

A production-ready HTML5 wood puzzle game with 10 levels.

## Play Now

1. Download and extract the ZIP
2. Open `index.html` in any browser
3. Start playing immediately

## Features

- 10 progressive levels
- Physics-based gameplay
- Touch and mouse controls
- Local progress saving
- Mobile optimized

## How to Play

1. Tap gold bolts to remove them
2. Remove all bolts from a plate to make it fall
3. Make the target plate fall to win
4. Red locked bolts unlock after certain moves

## Controls

- **Tap/Click**: Remove bolt
- **Restart Button**: Restart level
- **Menu Button**: Pause/Level select
